# In-browser replays with Pyodide Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Watch any Papersseum match on the website by re-running the real engine in the browser with Pyodide, on `/matches/[id]` and on a new `/replay` drop page, with the result checked against the recorded one.

**Architecture:** A new library module `papersseum/frames.py` re-runs a replay batch by batch and encodes viewer frames in the existing `PSRP` v1 layout. The library is shipped to the browser as a committed wheel (`web/public/engine/`), installed into Pyodide inside a Web Worker that streams frame batches to a canvas viewer. A pure `verdict()` compares the re-run result with the replay's result line and the database seats.

**Tech Stack:** Python 3.11+ / numpy (library), Pyodide 314.0.7 (Python 3.14, numpy 2.4.6) from jsDelivr, Next.js 16.4 App Router with Turbopack, React 19, TypeScript, Vitest 5, pytest, uv.

**Spec:** `web/specs/2026-10-15-pyodide-replays-design.md`. Read it before starting a task.

## Global Constraints

- Pyodide version is exactly `314.0.7`, loaded from `https://cdn.jsdelivr.net/pyodide/v314.0.7/full/`. The npm dev dependency `pyodide` is pinned to the same exact version.
- Only the current engine is shipped. A replay whose `engine_hash` differs (or is missing) still plays and is labelled as recorded on an older engine.
- The engine wheel and `manifest.json` are generated by `web/scripts/build_engine.py` and committed under `web/public/engine/`. Rerun it after **any** change under `papersseum/`; `tests/test_web_engine.py` fails until you do.
- Visual rules of the web app: no badges, pills, tags, gradients or decorative icons; plain buttons (`.btn`, `.btn-secondary`, `.link-button`); colours only from the CSS tokens in `web/app/globals.css` and the five player colours via `<Swatch>`. The verification result is a line of plain text.
- Replay files picked on `/replay` never leave the browser. Files over 1 MB (1,048,576 bytes) are refused before reading.
- Frames are streamed in batches of 50 decisions (`BATCH_FRAMES = 50`).
- Coverage is a percentage (0–100). Results agree when placements are identical and every coverage is within a relative `1e-5` (`|a - b| <= 1e-5 * max(1, |a|, |b|)`; the database column is `real` / float4, read back with about 6 significant digits).
- The engine modules listed in `papersseum/__init__.py` `_ENGINE_MODULES` are not modified, so `ENGINE_HASH` stays `94534ca788048520`.
- Python commands run from the repo root with `uv run --frozen ...`. Web commands run in `web/`.
- `web/AGENTS.md`: this is Next.js 16; check `web/node_modules/next/dist/docs/` before writing Next-specific code. React's lint rule `react-hooks/set-state-in-effect` is on: never call `setState` synchronously in an effect body.
- Commit messages: one sentence-case summary line in the repo's style, ending with the trailer `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. A dropped file's header `players` is malformed (not a list, entries that aren't objects, `slot` out of range or not an int, `bot_name` not a string or very long): the legend falls back to "Player N" per seat and nothing crashes. Pinned in Task 5 (`seatNames` tests).
2. A replay's result line is malformed or partial (placements not a permutation of 0–4, a score without `coverage`, wrong lengths): it is treated as no recorded result and never yields "Verified". Pinned in Task 5 (`parseResult` and `verdict` tests).
3. Match-page seats with `null` placement/coverage or a deleted bot (`name: null`): null facts are skipped, all-null seats count as nothing to check (no vacuous "Verified"), the name shows as "deleted bot". Pinned in Task 5.
4. A second file is dropped, or the visitor leaves, while a match is computing: the old run stops pulling batches and none of its late messages reach the new viewer. Pinned in Task 6 (`engine-client` tests).
5. The engine fails to load and the visitor presses Retry: Retry really retries (a crashed worker is replaced; a failed load is forgotten). Pinned in Task 6 (worker-crash test); the load-failure path is checked manually in Task 9.

```python
def decode(body):

    assert body[:4] == b"PSRP" and body[4] == 1

            off += 2

            off += 3 * n

        out.append((cells.copy(), [None if h == (255, 255) else h for h in heads]))
```

```python
"""Viewer frames: re-run a match and encode it for the web replay viewer.

Layout ("PSRP" v1, little-endian; read by web/lib/replay-format.ts):
b"PSRP", u8 version=1, u16 height, u16 width, u16 frames, u8 players, then
height*width cell bytes (frame 0), then per frame: players*(u8 row, u8 col)
heads (255,255 = dead) and, for every frame after the first, u16 n plus
n*(u16 cell index, u8 value).
Cell byte: 0xFE outside the arena, else low nibble = owner (0-4, 15 none),
high nibble = trail (0-4, 15 none); 0xFF is an empty cell.

The browser runs this module in Pyodide (web/workers/engine.worker.ts), one
batch at a time so a run can be cancelled between batches.
"""

import json
import struct

import numpy as np

import papersseum.constants as C
from papersseum.engine import Engine
from papersseum.geometry import arena_mask
from papersseum.replay_io import loads_replay

OUTSIDE = 0xFE
MAX_DECISIONS = C.TOTAL_TICKS // C.STEP_PER_DECISION       # 1800
_DIFF = np.dtype([("index", "<u2"), ("value", "u1")])       # 3 bytes, unpadded


def cell_bytes(owner, trail, mask):
    owner = owner.astype(np.int16)
    trail = trail.astype(np.int16)
    value = np.where(owner >= 0, owner, 15) | (np.where(trail >= 0, trail, 15) << 4)
    return np.where(mask, value, OUTSIDE).astype(np.uint8).ravel()


def check_replay(rep):
    """Raise ValueError with a plain-English reason unless the replay can be played.

    A valid log never ends the match early (the engine only stops at the final
    tick, after MAX_DECISIONS rows), so a checked replay has len(log) + 1 frames.
    """
    seed = rep.get("seed")
    if type(seed) is not int or seed < 0:
        raise ValueError("its seed is not a whole number of 0 or more")
    log = rep.get("action_log")
    if not isinstance(log, list) or not log:
        raise ValueError("it has no moves")
    if len(log) > MAX_DECISIONS:
        raise ValueError(f"it has {len(log)} decisions; a match has at most {MAX_DECISIONS}")
    for i, row in enumerate(log):
        if (not isinstance(row, list) or len(row) != C.N_PLAYERS
                or any(type(a) is not int or a not in (0, 1, 2) for a in row)):
            raise ValueError(f"decision {i + 1} is not {C.N_PLAYERS} moves of 0, 1 or 2")


class FrameEncoder:
    """Re-runs a match one batch of decisions at a time and encodes the frames.

    Call header() once, then next_batch() until it returns None, then result().
    """

    def __init__(self, seed, action_log, replay=None):
        self.replay = replay
        self.frames = len(action_log) + 1
        self._log = action_log
        self._eng = Engine(seed)
        self._mask = arena_mask()
        self._done_rows = 0
        self._prev = None

    def _cells(self):
        st = self._eng.state
        return cell_bytes(st.owner, st.trail, self._mask)

    def _heads(self):
        return b"".join(struct.pack("<BB", p.r, p.c) if p.alive else b"\xff\xff"
                        for p in self._eng.state.players)

    def header(self):
        st = self._eng.state
        height, width = st.owner.shape
        self._prev = self._cells()
        return (b"PSRP" + struct.pack("<BHHHB", 1, height, width, self.frames, len(st.players))
                + self._prev.tobytes() + self._heads())

    def next_batch(self, n=50):
        if self._prev is None:
            raise RuntimeError("call header() first")
        rows = self._log[self._done_rows:self._done_rows + n]
        if not rows:
            return None
        out = bytearray()
        for row in rows:
            actions = {p: row[p] for p in range(C.N_PLAYERS)}
            for k in range(C.STEP_PER_DECISION):
                self._eng.advance_tick(actions if k == 0 else None)
            out += self._heads()
            cur = self._cells()
            changed = np.flatnonzero(cur != self._prev)
            diffs = np.empty(len(changed), dtype=_DIFF)
            diffs["index"] = changed
            diffs["value"] = cur[changed]
            out += struct.pack("<H", len(changed)) + diffs.tobytes()
            self._prev = cur
        self._done_rows += len(rows)
        return bytes(out)

    @property
    def done(self):
        return self._done_rows == len(self._log)

    def result(self):
        """{"scores", "placements"} of the re-run match; only once every batch is out."""
        if not self.done:
            raise RuntimeError("the match has not been fully encoded yet")
        scores = [{k: (float(v) if isinstance(v, (float, np.floating)) else v) for k, v in s.items()}
                  for s in self._eng.scores()]
        return {"scores": scores, "placements": [int(p) for p in self._eng.placements()]}

    def result_json(self):
        return json.dumps(self.result())

    def meta_json(self):
        """JSON for the viewer: seed, both engine hashes, players and the recorded result."""
        from papersseum import ENGINE_HASH
        rep = self.replay or {}
        recorded = None
        if rep.get("placements") is not None and rep.get("scores") is not None:
            recorded = {"scores": rep["scores"], "placements": rep["placements"]}
        return json.dumps({
            "seed": rep.get("seed"), "engineHash": rep.get("engine_hash"), "shippedHash": ENGINE_HASH,
            "players": rep.get("players") or [], "recorded": recorded, "frames": self.frames,
        })


def open_replay(data):
    """Parse and check replay bytes (plain or gzipped JSONL); return a FrameEncoder.
    Raises ValueError with a reason a person can read."""
    try:
        rep = loads_replay(bytes(data))
    except Exception as e:
        raise ValueError("it could not be read as a replay file") from e
    if not isinstance(rep, dict):
        raise ValueError("it could not be read as a replay file")
    check_replay(rep)
    return FrameEncoder(rep["seed"], rep["action_log"], replay=rep)


def encode_frames(seed, action_log, batch=50):
    """Yield header() then every batch. Joined, this is the whole PSRP file body."""
    enc = FrameEncoder(seed, action_log)
    yield enc.header()
    while (chunk := enc.next_batch(batch)) is not None:
        yield chunk
```

```ts
// Runs the papersseum engine wheel inside Pyodide. Shared by the browser worker
// (workers/engine.worker.ts) and the Node determinism test, so both drive the
// engine through exactly the same calls.
import type { PyodideAPI } from "pyodide";
import type { MatchResult, ReplayMeta } from "@/lib/engine-protocol";

export const PYODIDE_VERSION = "314.0.7";
export const PYODIDE_CDN = `https://cdn.jsdelivr.net/pyodide/v${PYODIDE_VERSION}/full/`;

export type EngineManifest = { wheel: string; engine_hash: string; version: string };

// Python objects as seen from JavaScript (Pyodide proxies): only what we call.
type PyBytes = { toJs(): Uint8Array; destroy(): void };
type PyEncoder = {
  header(): PyBytes;
  next_batch(n: number): PyBytes | null | undefined;
  meta_json(): string;
  result_json(): string;
  destroy(): void;
};

// A replay the engine refused to read; the message says why, in plain words.
export class ReplayError extends Error {}

export async function installEngine(py: PyodideAPI, manifest: EngineManifest, wheel: Uint8Array): Promise<void> {
  await py.loadPackage(["numpy", "micropip"]);
  const path = `/tmp/${manifest.wheel}`;
  py.FS.writeFile(path, wheel);
  const micropip = py.pyimport("micropip");
  try {
    await micropip.install(`emfs:${path}`);
  } finally {
    micropip.destroy();
  }
}

// "Traceback ...\nValueError: it has no moves" -> "it has no moves"
export function pythonReason(error: unknown): string {
  const text = error instanceof Error ? error.message : String(error);
  const last = text.trim().split("\n").at(-1) ?? text;
  return last.replace(/^[A-Za-z_.]*(Error|Exception): /, "");
}

function takeBytes(proxy: PyBytes): Uint8Array {
  try {
    return proxy.toJs();
  } finally {
    proxy.destroy();
  }
}

export type ReplayRun = {
  meta: ReplayMeta;
  header: Uint8Array;
  nextBatch(frames: number): Uint8Array | null;
  result(): MatchResult;
  close(): void;
};

export function openReplay(py: PyodideAPI, bytes: Uint8Array): ReplayRun {
  const frames = py.pyimport("papersseum.frames");
  let encoder: PyEncoder;
  try {
    encoder = frames.open_replay(bytes) as PyEncoder;
  } catch (error) {
    if ((error as { type?: string }).type === "ValueError") throw new ReplayError(pythonReason(error));
    throw error;
  } finally {
    frames.destroy();
  }
  try {
    const meta = JSON.parse(encoder.meta_json()) as ReplayMeta;
    const header = takeBytes(encoder.header());
    return {
      meta,
      header,
      nextBatch: (n) => {
        const batch = encoder.next_batch(n);
        return batch == null ? null : takeBytes(batch);
      },
      result: () => JSON.parse(encoder.result_json()) as MatchResult,
      close: () => encoder.destroy(),
    };
  } catch (error) {
    encoder.destroy();
    throw error;
  }
}
```

```ts
export type Replay = {
  height: number;
  width: number;
  frames: number;
  players: number;
  initial: Uint8Array;
  heads: Uint8Array;
  diffStart: Uint32Array;
  diffIndex: Uint16Array;
  diffValue: Uint8Array;
};

const FIXED = 12; // "PSRP", version, height, width, frames, players

// Length of the header part: fixed fields, frame 0 cells and frame 0 heads.
export function headerLength(bytes: Uint8Array): number {
  if (bytes.length < FIXED) throw new Error("replay recording is truncated");
  if (String.fromCharCode(...bytes.subarray(0, 4)) !== "PSRP" || bytes[4] !== 1) {
    throw new Error("not a Papersseum replay recording");
  }
  const view = new DataView(bytes.buffer, bytes.byteOffset, bytes.byteLength);
  return FIXED + view.getUint16(5, true) * view.getUint16(7, true) + bytes[11] * 2;
}

// A replay that arrives in pieces: the header first, then batches of whole
// frame records (the engine worker streams them while it computes). Frames
// [0, available) can be drawn.
export class FrameStore implements Replay {
  readonly height: number;
  readonly width: number;
  readonly frames: number;
  readonly players: number;
  readonly initial: Uint8Array;
  readonly heads: Uint8Array;
  readonly diffStart: Uint32Array;
  diffIndex = new Uint16Array(4096);
  diffValue = new Uint8Array(4096);
  available = 1;
  private diffCount = 0;

  constructor(header: Uint8Array) {
    const length = headerLength(header);
    if (header.length < length) throw new Error("replay recording is truncated");
    if (header.length > length) throw new Error("replay recording has trailing bytes");
    const view = new DataView(header.buffer, header.byteOffset, header.byteLength);
    this.height = view.getUint16(5, true);
    this.width = view.getUint16(7, true);
    this.frames = view.getUint16(9, true);
    this.players = header[11];
    if (this.frames < 1) throw new Error("replay recording has no frames");
    const cells = this.height * this.width;
    this.initial = header.slice(FIXED, FIXED + cells);
    this.heads = new Uint8Array(this.frames * this.players * 2);
    this.heads.set(header.subarray(FIXED + cells), 0);
    this.diffStart = new Uint32Array(this.frames + 1);
  }

  get complete(): boolean {
    return this.available === this.frames;
  }

  append(bytes: Uint8Array): void {
    const view = new DataView(bytes.buffer, bytes.byteOffset, bytes.byteLength);
    const headBytes = this.players * 2;
    let off = 0;
    while (off < bytes.length) {
      if (this.complete) throw new Error("replay recording has trailing bytes");
      if (off + headBytes + 2 > bytes.length) throw new Error("replay recording is truncated");
      const frame = this.available;
      this.heads.set(bytes.subarray(off, off + headBytes), frame * headBytes);
      off += headBytes;
      const n = view.getUint16(off, true);
      off += 2;
      if (off + n * 3 > bytes.length) throw new Error("replay recording is truncated");
      this.reserve(this.diffCount + n);
      this.diffStart[frame] = this.diffCount;
      for (let k = 0; k < n; k++, off += 3) {
        this.diffIndex[this.diffCount] = view.getUint16(off, true);
        this.diffValue[this.diffCount] = bytes[off + 2];
        this.diffCount++;
      }
      this.diffStart[frame + 1] = this.diffCount;
      this.available = frame + 1;
    }
  }

  private reserve(needed: number): void {
    if (needed <= this.diffIndex.length) return;
    let size = this.diffIndex.length;
    while (size < needed) size *= 2;
    const index = new Uint16Array(size);
    index.set(this.diffIndex.subarray(0, this.diffCount));
    const value = new Uint8Array(size);
    value.set(this.diffValue.subarray(0, this.diffCount));
    this.diffIndex = index;
    this.diffValue = value;
  }
}

export function decodeReplay(bytes: Uint8Array): Replay {
  const length = headerLength(bytes);
  if (bytes.length < length) throw new Error("replay recording is truncated");
  const store = new FrameStore(bytes.subarray(0, length));
  store.append(bytes.subarray(length));
  if (!store.complete) throw new Error("replay recording is truncated");
  return store;
}

export const DECISIONS_PER_SECOND = 10;

// Frame (decision) index as match time: 835 -> "1:23".
export function clock(frame: number): string {
  const seconds = Math.floor(frame / DECISIONS_PER_SECOND);
  return `${Math.floor(seconds / 60)}:${String(seconds % 60).padStart(2, "0")}`;
}
```

```ts
// Whether a re-run match agrees with what was recorded, and how to say so.
// Inputs from replay files are untrusted: parseResult() and seatNames() accept
// anything and fall back instead of throwing.
import type { MatchResult, SeatScore } from "@/lib/engine-protocol";
import { percent } from "@/lib/format";

const SEATS = 5;
// Coverage is a percentage; match_players.coverage is float4, so values read
// back from the database differ from the engine's doubles by up to ~4e-6.
export const COVERAGE_TOLERANCE = 1e-5;

export type ExpectedSeat = { slot: number; name: string | null; placement: number | null; coverage: number | null };
type Facts = { place: number | null; coverage: number | null };
export type SeatDiff = { slot: number; got: { place: number; coverage: number }; recorded: Facts };
export type Verdict =
  | { kind: "verified" }
  | { kind: "mismatch"; seats: SeatDiff[] }
  | { kind: "older-engine"; engineHash: string | null }
  | { kind: "unchecked" };

const isInt = (v: unknown): v is number => Number.isInteger(v);
const isNumber = (v: unknown): v is number => typeof v === "number" && Number.isFinite(v);
const inSeats = (slot: unknown): slot is number => isInt(slot) && slot >= 0 && slot < SEATS;

// A replay's result line if it is well formed, else null.
export function parseResult(raw: unknown): MatchResult | null {
  if (typeof raw !== "object" || raw === null) return null;
  const { scores, placements } = raw as { scores?: unknown; placements?: unknown };
  if (!Array.isArray(placements) || placements.length !== SEATS || !placements.every(isInt)) return null;
  if ([...placements].sort((a, b) => a - b).join() !== "0,1,2,3,4") return null;
  if (!Array.isArray(scores) || scores.length !== SEATS) return null;
  const parsed: SeatScore[] = [];
  for (const s of scores) {
    if (typeof s !== "object" || s === null) return null;
    const { pid, coverage } = s as { pid?: unknown; coverage?: unknown };
    if (!inSeats(pid) || !isNumber(coverage)) return null;
    parsed.push({ pid, coverage });
  }
  return { scores: parsed, placements: placements as number[] };
}

function factsOf(result: MatchResult): Facts[] {
  const out: Facts[] = Array.from({ length: SEATS }, () => ({ place: null, coverage: null }));
  result.placements.forEach((slot, i) => {
    if (inSeats(slot)) out[slot].place = i + 1;
  });
  for (const s of result.scores) if (inSeats(s.pid)) out[s.pid].coverage = s.coverage;
  return out;
}

function factsOfSeats(seats: ExpectedSeat[]): Facts[] {
  const out: Facts[] = Array.from({ length: SEATS }, () => ({ place: null, coverage: null }));
  for (const s of seats) if (inSeats(s.slot)) out[s.slot] = { place: s.placement, coverage: s.coverage };
  return out;
}

const hasFacts = (facts: Facts[]) => facts.some((f) => f.place !== null || f.coverage !== null);

export function verdict(input: {
  shippedHash: string;
  engineHash: unknown;
  got: MatchResult;
  recorded: MatchResult | null;
  expected?: ExpectedSeat[];
}): Verdict {
  if (input.engineHash !== input.shippedHash) {
    return { kind: "older-engine", engineHash: typeof input.engineHash === "string" ? input.engineHash : null };
  }
  const references = [
    ...(input.recorded ? [factsOf(input.recorded)] : []),
    ...(input.expected ? [factsOfSeats(input.expected)] : []),
  ].filter(hasFacts);
  if (!references.length) return { kind: "unchecked" };

  const got = factsOf(input.got);
  const seats: SeatDiff[] = [];
  for (let slot = 0; slot < SEATS; slot++) {
    const mine = { place: got[slot].place ?? 0, coverage: got[slot].coverage ?? 0 };
    const disagreeing = references.find((ref) => {
      const r = ref[slot];
      const placeOff = r.place !== null && r.place !== mine.place;
      const coverageOff = r.coverage !== null && !(Math.abs(r.coverage - mine.coverage) <= COVERAGE_TOLERANCE);
      return placeOff || coverageOff;
    });
    if (disagreeing) seats.push({ slot, got: mine, recorded: disagreeing[slot] });
  }
  return seats.length ? { kind: "mismatch", seats } : { kind: "verified" };
}

const MAX_NAME = 40;

// One display name per seat: database names on the match page, else the
// replay header's bot_name, else "Player N".
export function seatNames(players: unknown, expected?: ExpectedSeat[]): string[] {
  const names = Array.from({ length: SEATS }, (_, slot) => `Player ${slot + 1}`);
  if (expected?.length) {
    for (const s of expected) if (inSeats(s.slot)) names[s.slot] = s.name ?? "deleted bot";
    return names;
  }
  if (!Array.isArray(players)) return names;
  for (const p of players) {
    if (typeof p !== "object" || p === null) continue;
    const { slot, bot_name } = p as { slot?: unknown; bot_name?: unknown };
    if (!inSeats(slot) || typeof bot_name !== "string" || !bot_name.trim()) continue;
    names[slot] = bot_name.trim().slice(0, MAX_NAME);
  }
  return names;
}

const ORDINALS = ["1st", "2nd", "3rd", "4th", "5th"];
const place = (n: number | null) => (n === null ? "—" : (ORDINALS[n - 1] ?? `${n}th`));

export function verdictText(v: Verdict, names: string[]): string {
  switch (v.kind) {
    case "verified":
      return "Verified: the engine reproduced this result.";
    case "unchecked":
      return "No recorded result to check this replay against.";
    case "older-engine":
      return v.engineHash
        ? `Recorded on an older engine (${v.engineHash.slice(0, 12)}…), so this result can't be verified.`
        : "Recorded on an older engine, so this result can't be verified.";
    case "mismatch":
      return (
        "Result mismatch: " +
        v.seats
          .map(
            (s) =>
              `${names[s.slot]} placed ${place(s.got.place)} with ${percent(s.got.coverage)} here, ` +
              `recorded ${place(s.recorded.place)} with ${percent(s.recorded.coverage)}`,
          )
          .join("; ") +
        "."
      );
  }
}
```

```ts
// The page's side of the replay engine: one worker per page, created on first
// use. Each run gets an id; messages for cancelled or finished runs are dropped.
import type { WorkerIn, WorkerOut } from "@/lib/engine-protocol";

type WorkerLike = Pick<Worker, "postMessage" | "addEventListener" | "terminate">;

export type EngineClient = {
  // Returns cancel(): stops the run and silences its remaining messages.
  run(bytes: Uint8Array, onMessage: (m: WorkerOut) => void): () => void;
};

export function createEngineClient(makeWorker: () => WorkerLike): EngineClient {
  let worker: WorkerLike | null = null;
  let nextId = 1;
  const listeners = new Map<number, (m: WorkerOut) => void>();

  const deliver = (m: WorkerOut) => {
    const listener = listeners.get(m.id);
    if (!listener) return;
    if (m.type === "done" || m.type === "error") listeners.delete(m.id);
    listener(m);
  };

  const getWorker = (): WorkerLike => {
    if (worker) return worker;
    const w = makeWorker();
    w.addEventListener("message", (e) => deliver((e as MessageEvent<WorkerOut>).data));
    w.addEventListener("error", () => {
      // The worker itself died. Fail every open run and start a fresh worker
      // next time, so the viewer's Retry really retries.
      w.terminate();
      if (worker === w) worker = null;
      for (const id of [...listeners.keys()]) {
        deliver({ type: "error", id, stage: "engine", message: "the replay engine stopped" });
      }
    });
    worker = w;
    return w;
  };

  return {
    run(bytes, onMessage) {
      const id = nextId++;
      listeners.set(id, onMessage);
      getWorker().postMessage({ type: "run", id, bytes } satisfies WorkerIn);
      return () => {
        if (listeners.delete(id)) worker?.postMessage({ type: "cancel", id } satisfies WorkerIn);
      };
    },
  };
}

let shared: EngineClient | null = null;

export function engineClient(): EngineClient {
  shared ??= createEngineClient(
    () => new Worker(new URL("../workers/engine.worker.ts", import.meta.url), { type: "module" }),
  );
  return shared;
}
```

```ts
// The replay engine: Pyodide plus the papersseum wheel, in a Web Worker so the
// page never freezes. Protocol in lib/engine-protocol.ts; the Python calls are
// in lib/engine-runtime.ts (shared with the Node determinism test).
import type { PyodideAPI } from "pyodide";
import { BATCH_FRAMES, type WorkerIn, type WorkerOut } from "@/lib/engine-protocol";
import {
  PYODIDE_CDN, ReplayError, installEngine, openReplay, pythonReason, type EngineManifest, type ReplayRun,
} from "@/lib/engine-runtime";

function post(message: WorkerOut, transfer: Transferable[] = []) {
  self.postMessage(message, { transfer });
}

// no-cache revalidates, so a rebuilt wheel with an unchanged file name is picked up.
async function fetchOk(url: string): Promise<Response> {
  const res = await fetch(url, { cache: "no-cache" });
  if (!res.ok) throw new Error(`${url}: HTTP ${res.status}`);
  return res;
}

let engine: Promise<PyodideAPI> | null = null;

// Loaded once and reused for every replay; a failed load is forgotten so the
// next run (the viewer's Retry) tries again.
function bootEngine(): Promise<PyodideAPI> {
  engine ??= (async () => {
    const url = `${PYODIDE_CDN}pyodide.mjs`;
    const { loadPyodide } = (await import(/* turbopackIgnore: true */ /* webpackIgnore: true */ url)) as typeof import("pyodide");
    const py = await loadPyodide({ indexURL: PYODIDE_CDN });
    const manifest = (await (await fetchOk("/engine/manifest.json")).json()) as EngineManifest;
    const wheel = new Uint8Array(await (await fetchOk(`/engine/${manifest.wheel}`)).arrayBuffer());
    await installEngine(py, manifest, wheel);
    return py;
  })();
  engine.catch(() => {
    engine = null;
  });
  return engine;
}

let current = 0; // the run allowed to keep going; 0 = none
const nextTurn = () => new Promise<void>((resolve) => setTimeout(resolve, 0));

async function run(id: number, bytes: Uint8Array) {
  post({ type: "status", id, stage: "loading-engine" });
  let py: PyodideAPI;
  try {
    py = await bootEngine();
  } catch (error) {
    post({ type: "error", id, stage: "engine", message: String(error) });
    return;
  }
  if (current !== id) return;
  post({ type: "status", id, stage: "computing" });

  let replay: ReplayRun;
  try {
    replay = openReplay(py, bytes);
  } catch (error) {
    if (error instanceof ReplayError) post({ type: "error", id, stage: "replay", message: error.message });
    else post({ type: "error", id, stage: "run", message: pythonReason(error) });
    return;
  }
  try {
    post({ type: "start", id, header: replay.header, meta: replay.meta }, [replay.header.buffer as ArrayBuffer]);
    for (;;) {
      await nextTurn(); // lets a cancel or a newer run arrive between batches
      if (current !== id) return;
      const batch = replay.nextBatch(BATCH_FRAMES);
      if (!batch) break;
      post({ type: "frames", id, bytes: batch }, [batch.buffer as ArrayBuffer]);
    }
    post({ type: "done", id, result: replay.result() });
  } catch (error) {
    post({ type: "error", id, stage: "run", message: pythonReason(error) });
  } finally {
    replay.close();
  }
}

self.addEventListener("message", (event: MessageEvent<WorkerIn>) => {
  const message = event.data;
  if (message.type === "cancel") {
    if (current === message.id) current = 0;
    return;
  }
  current = message.id;
  void run(message.id, message.bytes);
});
```

```tsx
"use client";

import { useCallback, useEffect, useRef, useState } from "react";
import { Swatch } from "@/components/swatch";
import { engineClient } from "@/lib/engine-client";
import type { ErrorStage, ReplayMeta, WorkerOut } from "@/lib/engine-protocol";
import {
  FrameStore, THEMES, applyFrame, buildColorTable, clock, headsAt, paintCells, type Theme,
} from "@/lib/replay-format";
import { parseResult, seatNames, verdict, verdictText, type ExpectedSeat } from "@/lib/replay-verdict";

export type ReplaySource = { url: string } | { bytes: Uint8Array };

const STEP_MS = 100; // 10 decisions per second at 1x: real match speed
const SPEEDS = [1, 2, 4];
const MAX_CATCH_UP = 20; // frames per animation tick after a hiccup

type Phase =
  | { kind: "fetching" }
  | { kind: "loading-engine" }
  | { kind: "computing" }
  | { kind: "done"; text: string }
  | { kind: "error"; stage: ErrorStage | "fetch"; message: string };

function errorText(phase: Extract<Phase, { kind: "error" }>, available: number): string {
  switch (phase.stage) {
    case "fetch":
      return "Couldn't fetch this replay.";
    case "engine":
      return "Couldn't load the replay engine.";
    case "replay":
      return `This isn't a Papersseum replay: ${phase.message}.`;
    case "run":
      return `The replay stopped at ${clock(Math.max(0, available - 1))}: ${phase.message}`;
  }
}

type Props = { source: ReplaySource; expected?: ExpectedSeat[] };

// Re-runs a match with the real engine in the browser and plays it. A Retry
// remounts the inner run, so every attempt starts from clean state.
export function ReplayViewer(props: Props) {
  const [attempt, setAttempt] = useState(0);
  return <ViewerRun key={attempt} {...props} onRetry={() => setAttempt((a) => a + 1)} />;
}

function ViewerRun({ source, expected, onRetry }: Props & { onRetry: () => void }) {
  const canvasRef = useRef<HTMLCanvasElement>(null);
  const storeRef = useRef<FrameStore | null>(null);
  const cellsRef = useRef(new Uint8Array(0));
  const imageRef = useRef<ImageData | null>(null);
  const frameRef = useRef(0);
  const themeRef = useRef<Theme>("light");
  const tableRef = useRef<Uint8ClampedArray | null>(null);
  const [frames, setFrames] = useState(0); // 0 until the header arrives
  const [available, setAvailable] = useState(0);
  const [frame, setFrame] = useState(0);
  const [playing, setPlaying] = useState(false);
  const [speed, setSpeed] = useState(1);
  const [phase, setPhase] = useState<Phase>("url" in source ? { kind: "fetching" } : { kind: "loading-engine" });
  const [names, setNames] = useState(() => seatNames(null, expected));

  const draw = useCallback(() => {
    const canvas = canvasRef.current;
    const store = storeRef.current;
    const ctx = canvas?.getContext("2d");
    if (!canvas || !ctx || !store) return;
    if (!imageRef.current) {
      canvas.width = store.width;
      canvas.height = store.height;
      imageRef.current = ctx.createImageData(store.width, store.height);
    }
    tableRef.current ??= buildColorTable(themeRef.current);
    paintCells(imageRef.current.data, cellsRef.current, tableRef.current);
    ctx.putImageData(imageRef.current, 0, 0);
    ctx.fillStyle = THEMES[themeRef.current].head;
    for (const head of headsAt(store, frameRef.current)) if (head) ctx.fillRect(head[1] - 1, head[0] - 1, 3, 3);
  }, []);

  // Light or dark board, following the system setting live.
  useEffect(() => {
    const dark = window.matchMedia("(prefers-color-scheme: dark)");
    const apply = () => {
      themeRef.current = dark.matches ? "dark" : "light";
      tableRef.current = buildColorTable(themeRef.current);
      draw();
    };
    apply();
    dark.addEventListener("change", apply);
    return () => dark.removeEventListener("change", apply);
  }, [draw]);

  // Fetch (match page) or take the bytes (drop page), then run the engine.
  useEffect(() => {
    let cancelled = false;
    let cancelRun = () => {};
    let meta: ReplayMeta | null = null;
    const autoplay = !window.matchMedia("(prefers-reduced-motion: reduce)").matches;

    const onMessage = (m: WorkerOut) => {
      switch (m.type) {
        case "status":
          setPhase({ kind: m.stage });
          break;
        case "start": {
          meta = m.meta;
          const store = new FrameStore(m.header);
          storeRef.current = store;
          cellsRef.current = store.initial.slice();
          frameRef.current = 0;
          setNames(seatNames(m.meta.players, expected));
          setFrames(store.frames);
          setAvailable(store.available);
          draw();
          break;
        }
        case "frames": {
          const store = storeRef.current;
          if (!store) return;
          const first = store.available === 1;
          try {
            store.append(m.bytes);
          } catch (error) {
            cancelRun();
            setPhase({ kind: "error", stage: "run", message: String(error) });
            return;
          }
          setAvailable(store.available);
          if (first && autoplay) setPlaying(true);
          break;
        }
        case "done": {
          if (!meta) return;
          const v = verdict({
            shippedHash: meta.shippedHash,
            engineHash: meta.engineHash,
            got: m.result,
            recorded: parseResult(meta.recorded),
            expected,
          });
          setPhase({ kind: "done", text: verdictText(v, seatNames(meta.players, expected)) });
          break;
        }
        case "error":
          setPhase({ kind: "error", stage: m.stage, message: m.message });
          break;
      }
    };

    (async () => {
      let bytes: Uint8Array;
      if ("bytes" in source) {
        bytes = source.bytes;
      } else {
        try {
          const res = await fetch(source.url);
          if (!res.ok) throw new Error(`HTTP ${res.status}`);
          bytes = new Uint8Array(await res.arrayBuffer());
        } catch (error) {
          if (!cancelled) setPhase({ kind: "error", stage: "fetch", message: String(error) });
          return;
        }
      }
      if (!cancelled) cancelRun = engineClient().run(bytes, onMessage);
    })();

    return () => {
      cancelled = true;
      cancelRun();
    };
  }, [source, expected, draw]);

  // Playback: advance at 10 decisions per second times the speed, waiting at
  // the edge of what the engine has computed so far.
  useEffect(() => {
    if (!playing) return;
    let raf = 0;
    let last = performance.now();
    const tick = (now: number) => {
      const store = storeRef.current;
      if (!store) return;
      const step = STEP_MS / speed;
      let steps = 0;
      while (now - last >= step && frameRef.current < store.available - 1 && steps < MAX_CATCH_UP) {
        frameRef.current++;
        applyFrame(cellsRef.current, store, frameRef.current);
        last += step;
        steps++;
      }
      if (steps) {
        draw();
        setFrame(frameRef.current);
      }
      if (frameRef.current >= store.frames - 1) {
        setPlaying(false);
        return;
      }
      if (steps === MAX_CATCH_UP || frameRef.current >= store.available - 1) last = now;
      raf = requestAnimationFrame(tick);
    };
    raf = requestAnimationFrame(tick);
    return () => cancelAnimationFrame(raf);
  }, [playing, speed, draw]);

  const seek = (target: number) => {
    const store = storeRef.current;
    if (!store) return;
    const to = Math.max(0, Math.min(target, store.available - 1));
    if (to < frameRef.current) {
      cellsRef.current.set(store.initial);
      frameRef.current = 0;
    }
    while (frameRef.current < to) {
      frameRef.current++;
      applyFrame(cellsRef.current, store, frameRef.current);
    }
    draw();
    setFrame(to);
  };

  const toggle = () => {
    const store = storeRef.current;
    if (!store) return;
    if (!playing && frameRef.current >= store.frames - 1) seek(0);
    setPlaying(!playing);
  };

  const ready = frames > 0;
  const status =
    phase.kind === "error"
      ? errorText(phase, available)
      : phase.kind === "done"
        ? phase.text
        : phase.kind === "fetching"
          ? "Fetching the replay…"
          : phase.kind === "loading-engine"
            ? "Loading the replay engine (one-time download)…"
            : `Computing the match… ${frames ? Math.floor((available / frames) * 100) : 0}%`;
  const canRetry = phase.kind === "error" && (phase.stage === "fetch" || phase.stage === "engine");
  const failedBeforeStart = phase.kind === "error" && !ready;

  return (
    <div className="replay">
      {!failedBeforeStart && (
        <div className="board">
          <canvas
            ref={canvasRef}
            width={120}
            height={120}
            hidden={!ready}
            role="img"
            aria-label="Replay of this match: five players' territories in the arena"
          />
          {!ready && <div className="replay-empty" />}
        </div>
      )}
      {ready && (
        <div className="actions replay-controls">
          <button type="button" className="btn-secondary" onClick={toggle}>
            {playing ? "Pause" : "Play"}
          </button>
          <input
            type="range"
            className="replay-scrub"
            min={0}
            max={frames - 1}
            value={frame}
            onChange={(e) => seek(Number(e.target.value))}
            aria-label="Match time"
          />
          <span className="num small">
            {clock(frame)} / {clock(frames - 1)}
          </span>
          <span className="replay-speeds">
            {SPEEDS.map((s) => (
              <button key={s} type="button" className="link-button" aria-pressed={speed === s} onClick={() => setSpeed(s)}>
                {s}×
              </button>
            ))}
          </span>
        </div>
      )}
      <ul className="list-plain replay-legend">
        {names.map((name, slot) => (
          <li key={slot} className="seat">
            <Swatch slot={slot} />
            {name}
          </li>
        ))}
      </ul>
      <p className="small replay-status" role="status">
        <span className={phase.kind === "error" ? "error-text" : "muted"}>{status}</span>
        {canRetry && (
          <>
            {" "}
            <button type="button" className="link-button" onClick={onRetry}>
              Retry
            </button>
          </>
        )}
      </p>
    </div>
  );
}
```

```ts
// Checks on a replay file a visitor picks, made before the file is read.
export const MAX_REPLAY_BYTES = 1024 * 1024;

export function replayFileProblem(file: { size: number }): string | null {
  if (file.size === 0) return "That file is empty.";
  if (file.size > MAX_REPLAY_BYTES) return "That file is too big to be a replay; real ones are a few KB.";
  return null;
}
```

```tsx
"use client";

import { useState } from "react";
import { ReplayViewer } from "@/components/replay-viewer";
import { replayFileProblem } from "@/lib/replay-input";

type Chosen = { id: number; name: string; source: { bytes: Uint8Array } };

// Pick or drop a replay file; it is read here and never uploaded. Choosing
// another file remounts the viewer, which cancels the run in progress.
export function ReplayDrop() {
  const [chosen, setChosen] = useState<Chosen | null>(null);
  const [problem, setProblem] = useState<string | null>(null);
  const [over, setOver] = useState(false);

  const take = async (file: File | undefined) => {
    if (!file) return;
    const issue = replayFileProblem(file);
    setProblem(issue);
    if (issue) return;
    const bytes = new Uint8Array(await file.arrayBuffer());
    setChosen((prev) => ({ id: (prev?.id ?? 0) + 1, name: file.name, source: { bytes } }));
  };

  return (
    <>
      <label
        className="drop-zone"
        data-over={over}
        onDragOver={(e) => {
          e.preventDefault();
          setOver(true);
        }}
        onDragLeave={() => setOver(false)}
        onDrop={(e) => {
          e.preventDefault();
          setOver(false);
          void take(e.dataTransfer.files[0]);
        }}
      >
        <input
          type="file"
          accept=".jsonl,.gz"
          onChange={(e) => {
            void take(e.target.files?.[0]);
            e.target.value = "";
          }}
        />
        Drop a replay file here, or <span className="link-button">choose one</span>.
        <br />
        <span className="muted small">
          A <code>.jsonl</code> or <code>.jsonl.gz</code> file. It stays on your computer.
        </span>
      </label>
      {problem && (
        <p className="error-text small" style={{ marginTop: 8 }}>
          {problem}
        </p>
      )}
      {chosen && (
        <section style={{ marginTop: 24 }}>
          <p className="mono muted" style={{ marginBottom: 10 }}>
            {chosen.name}
          </p>
          <ReplayViewer key={chosen.id} source={chosen.source} />
        </section>
      )}
    </>
  );
}
```
